# Paradise Nursery

A responsive React + Redux plant shop with a landing page, About Us section, product catalog and shopping cart.

## Features
- Get Started button opens the plant catalog
- Six plants grouped by category, with descriptions and prices
- Add to Cart button disables for products already in the cart
- Cart quantity updates, item removal, total item count and total cost
- Continue Shopping and Checkout (Coming Soon)

## Run locally
```bash
npm install
npm run dev
```

Built with React, Vite, Redux Toolkit and React Redux.
